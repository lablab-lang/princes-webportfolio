# Social Media VA Portfolio

A cute, minimal, and clean web portfolio for Social Media Virtual Assistants.

## Features

- ✨ Beautiful olive green color scheme
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- 🚀 Smooth animations
- 📝 Contact form
- 🎯 Service showcase
- 💼 Portfolio section

## How to Use

1. Open `index.html` in your web browser to view the portfolio
2. Customize the content in `index.html` with your own information
3. Adjust colors in `styles.css` if needed (CSS variables at the top)
4. Modify functionality in `script.js` as required

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --olive-green: #808000;
    --olive-light: #9B9B30;
    --olive-dark: #556B2F;
    --olive-pale: #BDB76B;
    --cream: #F5F5DC;
    --white: #FFFFFF;
    --text-dark: #333333;
    --text-light: #666666;
    --shadow: rgba(128, 128, 0, 0.1);
}
```

### Content
Update the following in `index.html`:
- Your name and title in the hero section
- About me text
- Services offered
- Portfolio items
- Contact information
- Social media links

### Images
Replace the emoji placeholders with actual images:
- Profile picture in the about section
- Portfolio project images
